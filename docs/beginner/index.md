# Beginner

Start here if you've never written TypeScript, or never finished a course. By the end you'll be compiling and running real programs from a Node project, and you'll have built a command-line app that persists data to disk.

## Lessons

| # | Lesson | You'll learn |
| --- | --- | --- |
| 1 | [Setup & your first program](01-setup-and-first-program.md) | installing Node and `tsc`, `tsconfig.json`, `console.log`, reading arguments and input |
| 2 | [Variables & basic types](02-variables-and-types.md) | `const` vs `let`, type annotations and inference, `number` `string` `boolean`, `any` vs `unknown` |
| 3 | [Numbers & math](03-numbers-and-math.md) | floating point, `Math`, `parseInt`/`Number`, `NaN`, `bigint`, safe integers |
| 4 | [Strings](04-strings.md) | template literals, common methods, UTF-16 surprises, string literal types |
| 5 | [Booleans & conditionals](05-booleans-and-conditionals.md) | `===`, truthiness, `&&` `\|\|` `??`, `if`, `switch`, ternaries |
| 6 | [Loops](06-loops.md) | `for`, `for...of`, `for...in`, `while`, `break`/`continue`, `entries()` |
| 7 | [Arrays & tuples](07-arrays.md) | typing arrays, `map`/`filter`/`reduce`, sorting, `readonly`, tuples |
| 8 | [Objects, Maps & Sets](08-objects-maps-sets.md) | object types, destructuring, spread, `Map`, `Set`, `Record` |
| 9 | [Functions](09-functions.md) | parameter and return types, defaults, rest, arrow functions, overloads, `void` and `never` |
| 10 | [`null`, `undefined` & narrowing](10-null-and-narrowing.md) | `strictNullChecks`, `?.`, `??`, type guards, why `!` is dangerous |
| 11 | [Files & error handling](11-files-and-error-handling.md) | `try`/`catch`/`finally`, `node:fs`, `node:path`, `process.argv` |
| 12 | [Capstone: task tracker](12-capstone-task-tracker.md) | put it all together in a real CLI app |

## How to work through it

- One lesson per sitting. Type every example. Do the exercises.
- Don't move on until the "Recap" all makes sense.
- Stuck? Re-read the "Common mistakes" section — your bug is probably there.

## When you're done

You should be able to explain every line of the capstone and add a new feature to it unaided. Then go to [Intermediate](../intermediate/index.md).
